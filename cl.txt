## 1. How the MPI Process Works

For your gear, the "depth" you see is actually the amount of fluorescent liquid trapped in the magnetic field leakage.

1. **Magnetization:** An electric current or magnetic yoke creates a magnetic field in the gear.
2. **Flux Leakage:** If there is a crack, the magnetic field "leaks" out into the air at that spot.
3. **Particle Application:** You spray a "bath" of iron particles coated in fluorescent dye.
4. **Capture:** The particles stick to the leakage area. Under **UV light**, the crack glows bright green/yellow against the purple/black gear.

### 1. How to "Step-Rotate" correctly

If you rotate the image by **10 degrees**, the crack moves in a circle. To generate the new `.txt` files automatically, you need to use a **Rotation Matrix**.

### 2. Python Script to Rotate Image + Labels

Instead of doing this manually (which is impossible for 400+ images), you can use this script. It takes your image and your YOLO `.txt` file, rotates them both, and saves the new ones.

```python
import cv2
import numpy as np
import math

def rotate_yolo_bbox(center_x, center_y, width, height, angle_deg, img_w, img_h):
    # Convert degrees to radians
    angle_rad = math.radians(-angle_deg) 
    
    # 1. Convert normalized to pixel coordinates
    px_x = center_x * img_w
    px_y = center_y * img_h
    
    # 2. Shift origin to image center
    cx, cy = img_w / 2, img_h / 2
    temp_x = px_x - cx
    temp_y = px_y - cy
    
    # 3. Apply rotation matrix
    rotated_x = temp_x * math.cos(angle_rad) - temp_y * math.sin(angle_rad)
    rotated_y = temp_x * math.sin(angle_rad) + temp_y * math.cos(angle_rad)
    
    # 4. Shift back and normalize
    new_x = (rotated_x + cx) / img_w
    new_y = (rotated_y + cy) / img_h
    
    return new_x, new_y, width, height # Width/Height stay same for small rotations

# EXAMPLE: Rotate 10 degrees
# new_coords = rotate_yolo_bbox(0.8, 0.5, 0.1, 0.1, 10, 1920, 1080)

```
